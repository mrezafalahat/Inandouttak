# Manabe Masaref | منابع و مصارف

نسخه اولیه اپلیکیشن موبایل Flutter برای مدیریت منابع و مصارف به‌صورت کاملاً لوکال.

## امکانات نسخه 0.1

- ثبت دستی ردیف مالی
- مثبت / منفی بودن سند
- تیک «در محاسبات باشد»
- نمایش کارت مالی
- نمایش جدول مالی
- محاسبه مانده تجمعی
- ذخیره لوکال با SQLite
- آماده برای اضافه کردن Import Excel

## اجرای پروژه

```bash
flutter pub get
flutter run
```

## ساختار

```text
lib/
├── models/
├── screens/
├── services/
├── utils/
└── widgets/
```

## مرحله بعد

در نسخه بعدی باید صفحه Excel Import کامل شود:
- انتخاب فایل Excel
- انتخاب ستون تاریخ، شرح، مبلغ
- تعیین مثبت یا منفی بودن فایل
- تشخیص رکوردهای تکراری
