# Tak Cash Flow / منابع و مصارف

نسخه تستی اپلیکیشن پیش‌بینی نقدینگی شرکت تک.

## قابلیت‌های این نسخه

- ثبت موجودی بانک‌ها به‌صورت دستی و محاسبه موجودی نقد کل
- ورود فایل اکسل اسناد دریافتنی و پرداختنی
- تطبیق فایل جدید با لیست قبلی:
  - چک‌های جدید اضافه می‌شوند
  - چک‌هایی که همچنان در فایل هستند حفظ می‌شوند
  - چک‌هایی که در فایل جدید نیستند از پیش‌بینی خارج می‌شوند
  - تیک‌های قبلی «داخل/خارج از محاسبه» روی موارد باقی‌مانده حفظ می‌شود
- ثبت دریافت و پرداخت دستی برای قول‌های آینده یا نیازهای نقدی
- امکان خارج کردن هر سند از پیش‌بینی با سوییچ
- پیش‌بینی روزانه نقدینگی با پرداخت‌ها در اولویت همان روز
- هشدار اولین روز کسری

## منطق اصلی

```
نقدینگی آینده = جمع موجودی بانک‌ها
+ اسناد دریافتنی انتخاب‌شده
- اسناد پرداختنی انتخاب‌شده
+ دریافت‌های دستی فعال
- پرداخت‌های دستی فعال
```

برای دریافتنی‌ها اگر ستون «تاریخ وصول یا واگذاری چک» در فایل باشد، همان تاریخ اثر نقدی استفاده می‌شود. اگر نباشد، تاریخ چک + ۳ روز لحاظ می‌شود.

## بیلد APK در GitHub Actions

این پروژه Android folder ندارد. Workflow خودش اجرا می‌کند:

```
flutter create --platforms=android --project-name manabe_masaref .
flutter pub get
flutter build apk --release
```

خروجی APK از بخش Artifacts قابل دانلود است.
