# Tak Cash Flow / منابع و مصارف

نسخه کامل‌تر و قابل بیلد اولیه.

## امکانات
- ثبت موجودی بانک‌ها
- ثبت دستی دریافت و پرداخت
- ورود فایل اکسل دریافتنی و پرداختنی
- Sync فایل جدید با لیست قبلی
- حفظ تیک داخل/خارج محاسبات
- خروج خودکار مواردی که در فایل جدید نیستند
- پیش‌بینی مانده کلی نقدینگی
